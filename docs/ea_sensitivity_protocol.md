# 欧氏对齐（EA）敏感性分析规则（探索性，运行前冻结）

**目的。** 检查 session 间协方差漂移是否影响历史数据的效果，以及 session-wise EA 能否改善“历史＋当前”。这是敏感性分析：不改变主设计，不改变已报告结果，也不因 EA 结果较好而重新选择主设计。只使用 Train 验证，不读取 Test/Static。

**方法位置。** EA 位于预处理（滤波、保护期与 A 规则排除）之后、16×16 窗口特征之前。对每个 session，参考协方差 R_s 为该 session 允许数据中所有保留 flash 的试次协方差算术平均（0–800 ms，逐通道时间去均值，ddof=1，µV²；与 `session_drift_descriptive_v1` 定义相同）。正则固定为 `(1−a)R + a·tr(R)/16·I`，a=0.001，运行前写死。每个试次 X 变换为 R_s^(−1/2)·X（对称特征分解）。

**实现等价性。** 16×16 特征是各通道的 50 ms 窗口均值，通道空间线性变换与时间平均可交换：mean_t(WX)=W·mean_t(X)。因此在缓存特征的每个窗口上左乘 W，与先对原始 epoch 对齐再提特征严格相等。运行时逐被试用原始 epoch 验证该等价性，并验证缓存特征与原始 epoch 重算一致。

**数据限制。**

| Session | 计算 R_s 可用数据 |
|---|---|
| S1 | S1 Train 全部 18 个字符（历史） |
| S2 | S2 Train 全部 18 个字符（历史） |
| S3 | 校准池前 k 个字符 |

不能使用 S3 最后 6 个验证字符、Test/Static 或任何未标注的当前 session 数据；否则属于转导使用。R_s 不使用标签。验证 flash 用 R_S3(k) 变换。k=0 时 S3 无可用数据，EA 对照只在 k=3、6、12 进行，k=0 不报告。

**对照条件。** 全部历史（H=6，S1+S2 共 36 字符），SWLDA 固定主实验设置。
- A：历史＋当前，不对齐（主设计；须逐被试精确复现 history_amount H=6 结果）。
- B：历史＋当前，session-wise EA（S1、S2、S3 各用自己的 R_s）。
- 仅当前：不对齐（须复现 history_amount H=0）。
- C：仅当前，EA（R_S3(k)），用于区分 EA 本身的作用。

**评估与统计。** 固定验证集 flash 级 ROC-AUC，排除规则与主实验一致（7,560 个 flash，保留 7,340 个）。每个 k 逐被试计算 B−A 和 C−仅当前；按被试配对 bootstrap 10,000 次，种子 20261126，百分位 95% 区间。输出逐被试差值表（标注 F_07、F_21）、宏平均差值与区间、逐被试差值图。字符准确率只描述。

**判断规则（运行前写定）。**
1. 只报告，不据此改变主设计或重新选择主设计。
2. 方向一致性：至少 8/10 名被试与宏平均差值同号才称“方向一致”；否则按被试报告，不用平均值下结论。
3. EEGNet 跟进触发条件（“明显变化”）：某个 k 下 B−A 宏平均区间不含 0、方向一致、且 |B−A| ≥ 0.01 AUC。本次只记录是否触发，不训练 EEGNet。

**诊断。** 记录每个 R_s 的样本 flash 数、最小特征值与条件数；R_S3(k) 与 R_S3(12) 的归一化 log-Euclidean 距离（k=3 时 R 稳定性）；以及 S1、S2 到 R_S3(k) 的距离。

**限制。**
- k=3 时 R_S3 只基于约 378 个 flash，估计可能不稳定。
- EA 是线性变换；SWLDA 随后在合并训练集上逐特征 z-score。z-score 是全局的，不能消除 session 间差异，EA 则在合并前逐 session 统一尺度并混合通道，两者交互需在结果中说明。
- 只检验 session-wise EA 一种变体；黎曼对齐等不在范围内。
- 只有 10 名被试、每人 6 个验证字符；区间为探索性不确定性描述，不作确认性显著性结论。

配置：`configs/ea_sensitivity.json`。运行：`python scripts/run_ea_sensitivity.py`。输出：`outputs/ea_sensitivity_v1/`。
